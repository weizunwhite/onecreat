OneCreat 使用教程

从下载安装到完成第一个硬件项目。凡是系统要你「手动点同意」的地方都用 ⚠️ 标了出来,照着做就行。

开始前你需要

  • 一台 Mac 或 Windows 电脑;
  • 一块 ESP32 或 Arduino 开发板 + 一根能传数据的 USB 线;
  • 管理员发给你的登录账号(手机号 + 密码)。

1下载并安装 OneCreat

macOS
  1. 下载 onecreat-mac.dmg,双击打开,把 OneCreat 图标拖进「应用程序」。
  2. 到「应用程序」里,右键点 OneCreat → 打开,弹窗里再点一次「打开」。
⚠️ 第一次必须右键打开,不能直接双击——直接双击 macOS 会拦,提示「来自身份不明的开发者」或「已损坏」。
如果右键也打不开:打开「系统设置 → 隐私与安全性」,拉到最下面,点「仍要打开」,再回去打开 OneCreat。
Windows
  1. 下载 onecreat-setup.exe,双击运行。
  2. 按提示一路「下一步」装完,桌面/开始菜单会出现 OneCreat。
⚠️ 如果弹出蓝色窗口「Windows 已保护你的电脑」:点「更多信息」→「仍要运行」。这是因为软件还没买微软签名,不影响使用。

2登录

  1. 打开 OneCreat,输入管理员发给你的 手机号 + 密码,点登录。
  2. 登录后,你只会看到管理员给你开通的功能(比如「硬件项目」);没开通的不显示,这是正常的。
✅ 这一步不需要任何系统同意。

3一键配好编译 / 烧录环境

  1. 进入「硬件」面板,点「一键安装工具链」。
  2. 它会自动下载编译/烧录所需的全部工具(arduino-cli + Arduino/ESP32 板卡核),装到你的用户目录里。
  3. 等进度条跑完(第一次几分钟,看网速),面板显示「已就绪」就好了。
✅ 这一步不需要管理员权限、不需要任何同意——它只是下载文件到你自己的目录。中途卡住多半是网络问题,等一等或重点一次。

4插上开发板

  1. 用 USB 数据线把 ESP32 / Arduino 板子插到电脑。
  2. 回到硬件面板,正常情况下能看到识别出的「串口」。
⚠️ 如果识别不到串口,多半是缺 USB 串口驱动(便宜板子常用 CH340 芯片)。按你的系统装一下:
macOS
  • 近几年的 macOS 大多自带 CH34x 驱动,通常免装——先换根好的数据线、换个 USB 口试试。
  • 仍识别不到:从 WCH 官网(wch.cn)下载 CH34x macOS 驱动,装完打开「系统设置 → 隐私与安全性」,会看到「已阻止来自开发者…的系统软件」,点「允许」,然后重启电脑,重新插板子。
Windows
  • 从 WCH 官网下载 CH340 Windows 驱动(CH341SER.EXE),运行 → 点「INSTALL」。
  • 装完拔掉再插上板子。

5做第一个项目

  1. 在硬件项目里,用大白话描述你要做什么。例如:「让 ESP32 板载 LED 每秒闪一次」。
  2. AI 会生成对应的 Arduino 代码。
  3. 点「编译」,等编译通过(第一次稍慢)。
  4. 点「烧录」,代码就写进板子了。
  5. 打开「串口监视器」,能看到板子的运行输出。

想改效果?改一句描述 → 重新生成 → 编译 → 烧录,这样一轮轮迭代就行。

常见问题 · 手动同意一览

OneCreat 打不开(Mac)
右键 → 打开;还不行就去「系统设置 → 隐私与安全性 → 仍要打开」。
OneCreat 打不开(Windows)
「Windows 已保护你的电脑」→ 更多信息 → 仍要运行。
一键装工具链卡住
它在下官方安装包,网络慢会久一点;等一会儿或重新点一次。
板子识别不到串口
装 CH340 / CP2102 USB 驱动(见第 4 步);Mac 装完要在「隐私与安全性」点允许并重启。
AI 提示「点数已用完」
联系管理员充值后即可继续。
提示「登录已失效」
退出重新登录即可。
遇到搞不定的,联系你的管理员 · 零一优创 OneCreat
