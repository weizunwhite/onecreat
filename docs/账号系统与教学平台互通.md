# 账号系统 ↔ 教学平台（teacher）互通纪要

> 给 AI 编码助手看的跨项目纪要。**在 onecreat 里碰到"登录 / 账号 / 权限 / 点数 / 档位 / 网关 / 计费"相关改动前，先读这份**，它讲清楚 onecreat 这个桌面客户端和教学平台是怎么一根线连起来的、两半代码分别在哪、改一件事要动哪两边。

## 一句话关系

**OneCreat 是教学平台（teacher）的 B 端桌面客户端。** 老师在教学平台被开通账号 + 分配功能后，用手机号登录 OneCreat 桌面端；OneCreat 的 AI 调用不走本地 key，而是走教学平台的 AI 网关，按机构点数计费，真实模型对老师隐藏（只见"标准/高级/旗舰"三档）。

- **对端仓库（平台）**：`/Users/zunwei/system/teacher`（Next.js + Supabase），其对应纪要在 `teacher/docs/onecreat-integration.md`
- **平台线上地址**：`https://t.weizunxy.com`（onecreat `platformBaseURL()` 默认值）

## 两种运行模式（本地 vs 平台）—— 这是 2026-07 踩过的坑

OneCreat 靠 `platformAccountEnabled()`（`desktop/accounts_app.go`）在两种模式间切：

| | 本地模式（开发默认） | 平台模式（正式打包版 / 联平台） |
|---|---|---|
| 触发 | 不注入 ldflags 且不设 env | 打包脚本注入 `defaultAccountMode=platform`，或设 `ONECREAT_ACCOUNT_MODE=platform` |
| 登录门 | **不弹**，直接进 app | **强制登录**（`App.tsx`：`session.platformMode && !session.loggedIn` → `<LoginGate>`） |
| AI 调用 | 用本机 `onecreat.toml`/`.env` 的 API key 直连 | 走平台 AI 网关，token 鉴权，按机构点数计费 |
| 功能门控 | `useCan` 默认全开 | 按机构分配的 `features[]` 逐个门控 |

**开关注入点**：`scripts/desktop-build.sh` 的 `-ldflags "... -X main.defaultAccountMode=platform"`，跟 `main.version` 同款。env 优先级高于 ldflags（正式版临时回本地：`ONECREAT_ACCOUNT_MODE=local`）。

> 历史：提交 `fff8e3ec`「本地优先模式」曾把登录门从 App.tsx 摘掉、账号层改成 env 默认关（为了调试免登录）。2026-07-13 用 `platformMode` 字段 + ldflags 默认值把登录门加回来——本地开发仍免登录，正式版强制登录。

## 账号数据流

```
老师(手机号+密码)
   │  POST /api/onecreat/login
   ▼
teacher 平台 ── 返回 {token, account, isAdmin, features[], tiers[], points}
   │  token 落盘 ~/.config/onecreat/session.json(0600)
   ▼
OneCreat 设网关 env(ONECREAT_GATEWAY_URL/TOKEN/TIER) → 重建所有标签 controller
   │  之后每条 AI 消息:
   ▼
POST {platform}/api/onecreat/v1/chat/completions  (OpenAI 兼容,Bearer token)
   │  平台按 tier 映射真实模型、扣点、擦除模型名
   ▼
每轮结束 GET /api/onecreat/session 刷新 points/tiers(余额实时下降)
```

## 接口契约（4 个，⚠️ 有一个不存在）

| 端点 | 客户端调用处 | 平台实现 | 说明 |
|---|---|---|---|
| `POST /api/onecreat/login` | `accountAuthenticate()` | `teacher/src/app/api/onecreat/login/route.ts` | body `{phone,password}`；返回 `{ok,token,account,isAdmin,features,tiers,points,error}` |
| `GET /api/onecreat/session` | `RefreshAccountSession()` | `teacher/src/app/api/onecreat/session/route.ts` | header `Bearer <token>`；返回 `{loggedIn,isAdmin,features,tiers,points}` |
| `POST /api/onecreat/v1/chat/completions` | `internal/provider/openai`（网关 provider） | `teacher/src/app/api/onecreat/v1/chat/completions/route.ts` | OpenAI 兼容透传代理 |
| `POST /api/onecreat/refresh` | `ensureFreshToken()` | **不存在** ⚠️ | 见下方偏差 |

**⚠️ refresh 偏差（已知、暂不修）**：客户端 `ensureFreshToken()` 想用 `refresh_token` 静默续期，但①平台 login **不返回** `refresh_token`/`expires_in`，②平台**没有** `/refresh` 路由。好在客户端是防御式的——`RefreshToken==""` 时直接 return，**不会真去打那个 404**。平台目前靠**把 JWT 有效期拉到 1 周**（teacher 提交 `df7d4eb`）兜底掉线。要根治得两边一起做：平台加 `/refresh` + login 下发 `refresh_token`/`expires_in`；客户端已就绪，会自动启用。

## 数据模型（都在平台侧）

- **功能权限**：`organizations.onecreat_features TEXT[]`（按机构套餐）。10 个 key，与客户端 `useCan(key)` 一一对应：`hardware / proposal / paper / lesson / tutorial / log / jinpeng / knowledge / ota / skills`（平台 `src/lib/onecreat/catalog.ts`）。超管(`role='admin'`)全开。
- **点数**：`organizations.onecreat_points NUMERIC` + 流水表 `onecreat_point_ledger`。**换算：点数 = AI 成本 USD × 1000**（`teacher/src/lib/onecreat/points.ts` `POINTS_PER_USD`）。客户端只读展示（`internal/billing`）。
- **档位**：`onecreat_tiers`(tier_index 1–3 → `ai_models.id`)。默认映射：**档1 标准 → deepseek-v4-flash；档2/3 高级/旗舰 → deepseek-v4-pro**。客户端切档 = `SetOnecreatTier(index)` → 写 `ONECREAT_TIER=tier-N` → 重建 controller。

## 🔴 红线：真实模型名绝不能泄露给客户端

平台把 tier 映射到真实 DeepSeek 模型是**计费与路由机密**。客户端侧兜底在 `internal/config/config.go` 的 `ModelPrivacyPolicy` + 网关 provider；平台侧把响应里的 `model` 改写成常量 `"onecreat"`、SSE 逐帧擦除。**别在 onecreat 加任何暴露底层模型名/服务商的代码路径或 prompt**；网关模式下也别让本地能新增自带 key 的 provider 绕开计量（`gatewayActive()` 后端已拦 `SaveProvider/SetModel/...`）。

## 跨仓库改动指南（改一件事要动哪两边）

| 想做的事 | 平台侧（teacher）改 | 客户端侧（onecreat）改 |
|---|---|---|
| 加一个功能权限 key | `src/lib/onecreat/catalog.ts` + 超管勾选 UI | 对应功能入口加 `useCan("<key>")` 门控 + mock `MOCK_ALL_FEATURES` |
| 改档位→模型映射 | `/admin/onecreat-tiers` 配置（`onecreat_tiers`表） | 无需改（客户端只发 tier-N） |
| 加登录续期(refresh) | 加 `/api/onecreat/refresh` + login 下发 `refresh_token` | 已就绪（`ensureFreshToken`），自动生效 |
| 调点数换算/计费 | `src/lib/onecreat/points.ts` + ledger RPC | 无需改（只读展示） |
| 客户端账号 UI/门控 | — | `desktop/accounts_app.go` / `LoginGate.tsx` / `App.tsx` / `lib/account.ts` |
