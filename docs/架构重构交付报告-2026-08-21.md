## 4. 最终架构摘要

```
        Desktop / CLI / Serve / ACP        ← 前端，只经 Controller
                    │
        ┌───────────▼───────────┐
        │  control.Controller   │  六个服务，各自持锁；Controller 自己无锁
        │  approval · session · │
        │  memory · mcp · ckpt  │
        │  · turnState          │
        └───────────┬───────────┘
    OneCreat 产品策略（memory / evidence / permission / billing / checkpoint）
                    │
        ┌───────────▼───────────┐
        │  engine.TurnEngine    │  一个方法：Start → TurnHandle{Cancel,Wait}
        └─────┬───────────┬─────┘
         native          dsh（已接线，装配根 fail-closed）
```

- **生命周期**：`runtime` 的 Process → Workspace → Session → Turn 四级全部接线；
  Workspace 按 root 引用计数共享，`boot.Factory` 是它的唯一账本。
- **配置**：`config.Env` 按工作区隔离；`engine` 是活配置项。
- **事件**：durable/ephemeral 分级 + V2 信封 + 权威快照与客户端对齐。
- **会话**：`internal/session` 是身份与元数据的唯一所有者，跨进程锁保护索引。
